# 🌿 LeafScan AI — Plant Leaf Disease Detection

AI-powered web app that detects plant diseases from a single leaf photo.

## 🚀 Live Demo
👉 [Click here to open LeafScan AI](https://leafscan-ai-zxep.onrender.com)

## 📊 Model
- Architecture: MobileNetV2 (Transfer Learning)
- Dataset: PlantVillage — 54,306 images, 38 classes
- Accuracy: 96.8% Top-1 | 99.1% Top-3

## 🛠️ Tech Stack
Python · TensorFlow · Keras · Flask · HTML · CSS · JavaScript
